# terraform-aws-jaws-ci

Terraform modules for GitHub Actions on AWS without long-lived keys: OIDC roles for plan, apply, preview, release and task jobs, and a catalog of least-privilege policies

The modules are on their way: this is the initial scaffold. Once the first
version is released they are published on the
[Terraform Registry](https://registry.terraform.io/modules/jwallace145/jaws-ci/aws/latest)
as `jwallace145/jaws-ci/aws`.
